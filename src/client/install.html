install the bridge

back to the planner

The planner reads the public course catalog on its own. To match it against your degree it needs your own Self-Service session, and a web page cannot borrow one. The bridge is a small extension that asks Colleague on your behalf and hands the answer to this page.

Cedarville has not published it to the Chrome Web Store, so Chrome will only load it as an unpacked folder. That is four steps and it is the same thing the Web Store would do, minus the review.

  1. download the bridge
  2. Unzip it, and keep the folder somewhere you will not delete by accident.
  3. Open chrome://extensions, and turn on Developer mode at the top right.
  4. Press Load unpacked and pick the folder you unzipped. It should contain manifest.json directly.

Then open Self-Service in another tab and sign in. Come back here and press capture requirements.

what it can and cannot do

  • It reads your degree evaluations and the course catalog on your session, and hands them to this page and to a companion on your own machine if you run one.
  • It can write courses onto your Colleague degree plan, and only ones you have confirmed on screen first. It never registers you for anything.
  • It talks to Self-Service, to this planner, and to 127.0.0.1. Nothing else, which the manifest states and Chrome enforces.
  • Your transcript is never written to the planner's server. The server holds the course catalog, which is the same for everybody.

when a capture stops working

Almost always the same thing: the extension updated and a Self-Service tab is still running the old copy of it. Reload the extension at chrome://extensions, then reload the Self-Service tab. The planner says so when it can tell.
